# NoahSmo Homebrew Tap

```sh
brew install --cask noahsmo/tap/<cask>
```

| Cask | Description |
|---|---|
| [clawdio](https://github.com/NoahSmo/clawdio) | Claude Code quota and agent status in the notch |
| [hiddenbar](https://github.com/NoahSmo/HiddenBar) | Hide menu bar icons (works on macOS 27) |
| [orchestraclaude](https://github.com/NoahSmo/OrchestraClaude) | Feature-first orchestrator for Claude Code agents (Apple Silicon) |
